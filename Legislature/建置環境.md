
## 安裝
> 安裝 Node.js (基礎環境)
>> https://nodejs.org/en/download
>
> 安裝完後，在終端機輸入 node -v。看到版本號（例如 v20.x.x）就代表成功了。
> 
> 輸入以下指令來安裝 Firebase 全域工具：
> 
>`npm install -g firebase-tools`

## 建立環境
> ➀ 建立要放置 Firebase 專案的資料夾
> 
> ➁ 開啟終端機進入資料夾

> 方法一：最直覺的「拖拉法」（推薦！）
>> 1. 在終端機輸入 cd（後面加一個空格）。
>> 
>> 2. 打開檔案總管，找到你建立好的資料夾。
>> 
>> 3. 用滑鼠按住該資料夾，直接拖進終端機視窗裡。
>> 
>> 4. 終端機會自動幫你填好完整路徑，直接按 Enter 即可。

>方法二：處理「跨磁碟機」問題
>> 如果你原本在 C:\，但資料夾建在 D:\，只輸入 cd 是跳不過去的。你需要加上 /d 參數：
>> 
>> 例如：`cd /d "D:\Firebase Projects\MyWeb"`
>>

## 登入並初始化專案
*請切換路徑到你存放 HTML 網頁的資料夾（例如：cd Desktop/my-project），然後依序執行：
1. 登入 Firebase
`firebase login`
*這會自動跳出瀏覽器，請登入你的 Google 帳號並點擊「允許」。
2. 初始化 Hosting 服務
`firebase init hosting`
執行後，終端機會出現互動式選單，請按照以下建議選擇：
Project Setup: 選擇 Use an existing project (找到你之前在 Firebase Console 建立的那個專案)。
Public Directory: 輸入 public。
註：Firebase 會建立一個 public 資料夾，稍後請把你的 index.html 等檔案移進去。
Configure as a single-page app: 輸入 N (因為你有複數的 HTML 檔案，如首頁和私人頁面)。
Set up automatic builds and deploys with GitHub: 輸入 N (暫時先不用)。

這一步是決定你的網站要具備哪些功能的關鍵。根據你的需求（建立私人網頁、上傳 HTML、實作登入後存取），請按照以下建議操作：
1. 該選擇哪幾項？
請使用 空白鍵 (Space) 勾選以下這兩項，選好後按 Enter：

Hosting: Set up deployments for static web apps

理由： 這是最重要的！它負責幫你把 HTML/CSS/JS 檔案儲存到 Google 的雲端空間並給你一個網址。

Emulators: Set up local emulators for Firebase products (建議選)

理由： 這能讓你在電腦上「模擬」雲端環境，測試你的「登入跳轉」功能是否正常，而不需要每次都上傳。

=== Hosting Setup



Your public directory is the folder (relative to your project directory) that

will contain Hosting assets to be uploaded with firebase deploy. If you

have a build process for your assets, use your build's output directory.



? What do you want to use as your public directory? (public)



甚麼一絲

這句話的意思是問你：「哪一個資料夾要當作你的網站內容？」

Firebase 需要知道你電腦裡的哪一個資料夾放著那些 .html、.css、.js 檔案，它好把那個資料夾的內容「整包上傳」到雲端伺服器。

詳細解釋：
(public)：括號內是預設值。如果你直接按 Enter，Firebase 就會在你現在的目錄下自動建立一個名為 public 的資料夾。

為什麼要這樣分？：因為一個專案可能包含很多檔案（例如設定檔、備份、原始碼），但你並不想把「所有檔案」都給網路上的路人看。你只需要把**「要公開給別人看的檔案」**放進這個 public 資料夾即可。

你現在該怎麼做？
直接按 Enter：接受預設名稱 public。

搬移檔案：按完 Enter 後，你會看到 VS Code 左側出現了 public 資料夾。請把你的 index.html、login.html 以及你想保護的「私人網頁」檔案，全部拖進去這個 public 資料夾內。

接下來會遇到的問題：
Configure as a single-page app (rewrite all urls to /index.html)?

請輸入：N (然後按 Enter)

原因：因為你有好幾個獨立的網頁（登入頁、私人頁），選 N 才能讓每個網頁有自己的網址。

Set up automatic builds and deploys with GitHub?

請輸入：N (然後按 Enter)

原因：這一步我們先手動上傳就好，比較簡單。

💡 溫馨小提醒
一旦你完成這些步驟，你的專案資料夾會變得很乾淨：

根目錄：只有 firebase.json 等設定檔。

public/ 資料夾：裡面才是你辛苦寫出來的網頁。

=== Emulators Setup

? Which Firebase emulators do you want to set up? Press Space to select emulators, then

Enter to confirm your choices.

>( ) App Hosting Emulator

 ( ) Authentication Emulator

 ( ) Functions Emulator

 ( ) Firestore Emulator

 ( ) Database Emulator

 ( ) Hosting Emulator

 ( ) Pub/Sub Emulator

這一步是在設定你的**「本地開發實驗室」**。所謂的 Emulator（模擬器），就是讓你在電腦上跑一個「假的 Firebase」，這樣你不用每次改一個字就上傳一次，可以在本地測好再出貨。

1. 該選哪幾個？
請使用 空白鍵 (Space) 勾選以下兩項，然後按 Enter：

Authentication Emulator：這非常重要！因為你要測試「登入後才能進入私人網頁」的功能，這個模擬器可以讓你測試假帳號登入。

Hosting Emulator：這會幫你在電腦上開一個虛擬網址（例如 localhost:5000），讓你預覽你的 HTML 檔案。

2. 接下來的設定（一路按 Enter 即可）
選完按 Enter 後，Firebase 會問你幾個關於埠號（Port）的問題，通常直接一路按 Enter 接受預設值即可：

Which port do you want to use for the auth emulator? (9099) → 按 Enter。

Which port do you want to use for the hosting emulator? (5000) → 按 Enter。

Would you like to enable the Emulator UI? (Yes) → 按 Enter。

註：這個 UI 超好用，它會提供一個網頁介面讓你管理測試帳號。

Which port do you want to use for the Emulator UI? (4000) → 按 Enter。

Would you like to download the emulators now? (Yes) → 按 Enter。

這時會下載一些必要的檔案，需要等它跑完。

3. 完成初始化後，你的下一步
當你看到 ✔ Firebase initialization complete! 時，恭喜你，你的筆電已經變成一個強大的開發基地了！

現在請檢查你的 VS Code 左側檔案欄：

找到 public 資料夾。

把你原本寫好的 立法院網頁、成員卡片、login.html、私人頁面 全部拖進去這個 public 資料夾。

在終端機輸入：

Bash
firebase emulators:start
輸入完後，你會看到一串網址。打開其中的 Hosting URL，你就能在不聯網的情況下，看到你的網頁跑起來了！
---
當你已經在本地測試完成（不管是透過 firebase emulators:start 還是 firebase serve），準備好要讓全世界（或是你的朋友）看到你的網頁時，最後一步非常簡單且充滿成就感。

請在 VS Code 的終端機輸入以下指令：

第一步：執行發布指令
在你的專案根目錄（即包含 firebase.json 的那個資料夾）輸入：

Bash
firebase deploy
這行指令會執行以下動作：

打包： 將你 public 資料夾內的所有檔案打包。

上傳： 透過加密通道傳送到 Google 的 Firebase Hosting 伺服器。

生效： 自動配置 SSL 憑證（讓你的網址變成安全的 https）。

第二步：獲取你的正式網址
上傳完成後，終端機會出現幾行字，最後一行就是你的專案網址，看起來會像這樣：

✔ Deploy complete!

Project Console: https://console.firebase.google.com/project/your-project-id/overview Hosting URL: https://your-project-id.web.app

你可以直接點擊那個 Hosting URL，這就是可以在互聯網上公開連線的正式網址了！
