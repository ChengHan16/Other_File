「黑暗森林法則」是劉慈欣科幻小說《三體II：黑暗森林》中提出的宇宙社會學假想，解釋了費米悖論。其核心观点認為：宇宙是一座黑暗森林，每個文明都是帶槍的獵人，因生存需求和猜疑鏈，任何暴露存在的生命將迅速被消滅。

黑暗森林法則的核心內容：
基本背景： 宇宙總量有限，但文明的擴張需求是無限的。
生存原則： 生存是文明的第一需要。
技術爆炸： 文明技術可能在短時間內飛躍，導致弱小文明瞬間具備摧毀強大文明的能力。
猜疑鏈： 文明間無法判斷彼此的善惡（善意或敵意），且無法確認對方是否會判斷自己為善意，這種信任缺失會導致無限猜疑。
