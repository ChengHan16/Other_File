### 一、打開終端機，輸入以下指令（安裝 Unsloth AI 框架）<br>
> Mac 版本｜
```
curl -fsSL https://unsloth.ai/install.sh | sh
```
> Windows 版本｜（使用 PowerShell 系統管理員）
```
> irm https://unsloth.ai/install.ps1 | iex
```
### 二、安裝完成後打開瀏覽器
輸入：http://127.0.0.1:8888
### 三、點選 Start Onboarding 並設定新密碼登入
### 四、選擇模型：
- 類型 → 多模態 Vision（可以看圖、可以對話）
- Model 搜尋：Gemma 4 E4B（推薦，iPhone 等級的電腦就能跑）
- 或 Gemma 4 E2B（更輕量，老電腦也 OK）
### ⚠️ 小提醒：
語言模型的大小與能力取決於你的顯示卡記憶體
建議一開始先用小一點的版本測試，跑順了再換大的
